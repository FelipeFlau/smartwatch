Histórico do firmware

Todas as versões do relógio ESP32-S3 (ST7735 128×160, touch XPT2046, SD em SPI): o que foi corrigido, o que entrou de novo e o que mudou em cada entrega — com o motivo registrado, para que o mesmo bug não volte sem aviso.

— versões última: — ESP32-S3 N16R8 · 128×160 · LVGL 8.4 Repositório Releases YouTube Instagram

Cada versão é lançada no GitHub como SmartRolex ProMx V0.NN PREV (preview: ainda tem bug conhecido ou falta validar no relógio) ou SmartRolex ProMx V0.NN REALESE (a correção/implementação está completa e funcionando).

Como isso é mantido. A fonte é um único arquivo de dados: versoes.js (neste repositório, ao lado de estilo.css e app.js; no projeto local ficam em docs/assets/). Cada item é um release com listas de corrigido, adicionado e alterado. O index.html publicado é a junção desses arquivos em um só — versão nova = um item novo no topo do array.

Sobre a numeração. v0.NN é o índice do release na ordem em que foi entregue — não é semver. No GitHub cada um virou um release chamado SmartRolex ProMx V0.NN PREV ou SmartRolex ProMx V0.NN REALESE. O detalhe técnico completo de cada rodada fica em STATUS.md (raiz do repositório) e, para o cartão SD, em analise_sd.md.

Quando um item está marcado validar no relógio, o código está pronto e compilando, mas o comportamento depende de hardware (rádio, cartão, energia) e ainda não foi confirmado no pulso.
